**0.1.0alpha2-7** makes system keyboard layout tracking, composed Mac accents, and terminal Option+Up package defaults. This is an experimental package for x86-64 Omarchy 4.0.x / Hyprland 0.56.x.

## Keyboard changes

- Remote input follows the selected physical system keyboard layout and variant, with a composed-character fallback for Western European accents.
- Existing screen-sharing connections update after held keys are released. Changing layouts also refreshes the virtual keyboard so desktop input methods receive the new map.
- Option+Up works in Foot, Omarchy agent, Alacritty, Kitty, and Ghostty terminals. The package also handles local Mod5+Up with accent layouts. Plain Up and other applications retain their normal behavior.
- These defaults require no personal service keyboard override or shortcut snippet. Existing setup, settings, and passwords are preserved when upgrading.

Revision 7 includes the keyboard defaults developed in revision 6 and fixes the stale input-method map found during its live acceptance test. Revision 6 was not published.

## Install or upgrade on the Omarchy host

Download **mac-native-screenshare-0.1.0alpha2-7-x86_64.pkg.tar.zst** and **SHA256SUMS**, or run:

```bash
mkdir -p ~/Downloads/mac-native-screenshare-r7
cd ~/Downloads/mac-native-screenshare-r7
mns_release_url=https://github.com/LoFenk/mac-native-screenshare/releases/download/v0.1.0-alpha.2-r7
curl -fLO "$mns_release_url/SHA256SUMS" &&
curl -fLO "$mns_release_url/mac-native-screenshare-0.1.0alpha2-7-x86_64.pkg.tar.zst" &&
sha256sum -c SHA256SUMS --ignore-missing &&
sudo pacman -U ./mac-native-screenshare-0.1.0alpha2-7-x86_64.pkg.tar.zst
```

For a new installation, run `mac-native-screenshare setup` and then `mac-native-screenshare start`. An upgrade stops an active share; run `mac-native-screenshare start` afterward. The viewing Mac uses its built-in Screen Sharing app. Install this Arch package on the Omarchy host, including supported Intel Mac hardware running Omarchy.

The **.src.tar.gz** attachment is the complete rebuildable source bundle, including the modified dependencies and authoritative outer recipe. GitHub's automatic source archives are not that complete bundle. **sources.json** records the exact built snapshots; the release tag identifies the later packaging/documentation commit. Usage, build details, third-party notices, and checksums are included as attachments.

## Verification

The full build passed four NeatVNC suites, three WayVNC suites, 13 protocol/network tests, 56 lifecycle tests, seven keyboard-policy tests, five package-transaction tests, four supervisor tests, and Lua/hook/shell checks. Binary/source archive verification and a temporary-root revision 6→7 upgrade/removal check passed.

This exact package was installed locally through pacman. With the personal workarounds removed, authenticated VNC input produced the expected accents, plain Up, and Option+Up sequences in Foot and the Omarchy agent terminal. A physical system-layout change US Macintosh→French→US Macintosh synchronized one continuous VNC connection with Fcitx5 active; accents and Option+Up worked after both changes. Holding Option deferred the map update until release. The original system layout and credential were preserved, all 45 installed files passed integrity verification, and sharing remained healthy.
