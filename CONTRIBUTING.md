# Contributing

This is an experimental, independent project. Feedback from the documented second-machine and Mac acceptance checks is welcome. Report add-on problems in this repository rather than sending them directly to Omarchy, WayVNC, or NeatVNC.

Include the package version, Omarchy/Hyprland versions, the operation attempted, expected behavior, and the smallest reproducible example. Remove passwords, private addresses, hostnames, and personal file paths from diagnostic output before posting it. Discuss substantial behavior changes in an issue before preparing a pull request.

AI-generated contributions are accepted here when clearly disclosed, tested, and explained with their known limits. The project-specific implementation, tests, packaging, and documentation were produced using OpenAI Codex at Paul Stoica's direction. That disclosure does not imply independent human review. Preserve upstream authorship and license notices.

Use the complete release source bundle and the checks described in [PACKAGING.md](docs/PACKAGING.md) to reproduce a build. Runtime changes also require the relevant lifecycle, protocol, and desktop acceptance checks; passing isolated tests alone does not establish a working graphical session.

Each upstream project sets its own contribution policy. This repository's policy does not authorize submitting AI-generated patches to a project that prohibits them. Any later upstream work must follow that project's current rules.

Be respectful, focus criticism on the work, and do not harass people or publish their private information. Project contact: Paul Stoica <paul@totallynormal.io>.
